# DoctorDTO

## Описание проекта:
Приложение для записи пациентов - это система для удобного и эффективного управления медицинскими приёмами в поликлиниках и медицинских центрах. Она позволяет пациентам быстро записаться на приём к врачу, а медицинскому персоналу — легко управлять расписанием и обрабатывать заявки.
